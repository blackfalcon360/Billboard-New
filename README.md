# Billboard

ایپ میں لکھا ہوا متن پوری اسکرین پر لینڈ اسکیپ میں بل بورڈ / LED سائن کی طرح دکھاتی ہے۔

## ایپ کیا کرتی ہے
- متن لکھیں (کئی سطریں بھی) اور نیچے براہ راست پری ویو دیکھیں۔
- انداز: چلتا ہوا متن (اسکرالنگ) یا ساکن (اسکرین کے حساب سے خود فٹ)۔
- رفتار کا سلائیڈر، 8 رنگ متن کے اور 8 پس منظر کے، موٹا متن، جھلملانا (Blink)، LED ڈاٹ اسٹائل، زیادہ سے زیادہ برائٹنس۔
- چلنے کی سمت: خودکار (اردو/عربی دائیں کو، انگریزی بائیں کو)، یا ← / → اپنی مرضی سے۔
- "پوری اسکرین پر دکھائیں" دبائیں تو اسکرین خود لینڈ اسکیپ میں گھوم کر ساری پٹیاں چھپا لیتی ہے اور اسکرین آن رہتی ہے۔
- بل بورڈ پر: ٹیپ = رکیں/چلیں، والیوم بٹن = رفتار کم/زیادہ، بیک = واپس۔
- محفوظ متن: آخری 20 متن یاد رہتے ہیں، ٹیپ کر کے دوبارہ استعمال کریں۔
- زبان: اردو / English / العربية؛ لائٹ اور ڈارک موڈ؛ باہر نکلنے سے پہلے تصدیق۔

## بِلڈ
1. فولڈر GitHub پر اپ لوڈ کریں۔
2. Actions میں "Build APK" چلے گا۔
3. Artifacts سے `Billboard-APK` ڈاؤن لوڈ کریں۔

## پابندیاں
- ایڈیٹر اسکرین portrait میں ہے؛ صرف بل بورڈ اسکرین لینڈ اسکیپ میں کھلتی ہے (دونوں لینڈ اسکیپ سمتیں چلتی ہیں)۔
- AndroidX یا بیرونی لائبریری نہیں؛ کوئی پرمیشن نہیں؛ انٹرنیٹ نہیں۔
- فونٹ فون کا اپنا ہے؛ اردو کے لیے نسخ انداز ہو گا، نستعلیق نہیں۔
- بہت لمبا متن ساکن انداز میں چھوٹا ہو جاتا ہے؛ ایسے میں چلتا ہوا انداز بہتر ہے۔
